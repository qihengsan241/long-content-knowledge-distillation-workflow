# 第三方工具接入模板

用于记录未来接入 B站、抖音、小红书、播客音频或其他平台的第三方文本提取工具。

## 基本信息

- 工具名称：
- 工具链接：
- 支持平台：
- 输入类型：
- 输出类型：
- 是否支持时间戳：
- 是否需要登录或 Cookie：
- 是否需要 API Key：

## 调用方式

```bash
# 示例
third-party-tool --input "{input}" --output "{output}"
```

约定：

- `{input}` 表示原始 URL 或本地文件路径。
- `{output}` 表示第三方工具需要写入的输出文件路径。
- 优先让第三方工具输出标准逐字稿 JSON。

## 标准输出要求

第三方工具最好直接输出：

```json
{
  "来源链接": "",
  "平台": "",
  "标题": "",
  "作者": "",
  "时长": "",
  "语言": "",
  "是否有时间戳": true,
  "逐字稿": [
    {
      "开始时间": "00:00:00",
      "结束时间": "00:00:05",
      "文本": ""
    }
  ],
  "原始文本": "",
  "提取方式": "",
  "警告信息": []
}
```

## 如果第三方输出不是标准格式

记录原始输出样例：

```json
{}
```

然后在 `核心模块/适配器.py` 中新增适配类，把原始输出转换为 `TranscriptDocument`。

## 禁止事项

- 不要只根据标题、简介、封面或评论生成正文。
- 没有逐字稿或正文时，不要进入知识脱水。
- 不要把知识脱水 Prompt 写进适配器。
