# 3. 脱水导航时间轴

**本节只做一件事：决定每一段怎么处理。不展开内容，不写摘要。**

请将全文按逻辑节点拆解，填入以下表格。你的任务是分配处理决策，不是总结内容。

分类标准：

🟡【关键推演】— 速览
🔴【核心干货/反直觉】— 进入第4节展开
🔵【体验/体感段落】— 保留，需填写回看理由
⚪【低价值/可删除】— 忽略，不进入后续任何步骤

输出表格：

| 时间戳/位置 | 知识模块名（5字以内） | 类型 | 处理决策 | 回看理由（仅🔵填写，其余留空） |
|---|---|---|---|---|
|  | ... | 🟢/🟡/🔴/🔵/⚪ | 跳过/速览/→第4节/回看/忽略 |  |

执行规则：

1. 模块名只写定位名称，不写摘要。例如写"注意力分配模型"，不写"作者说注意力很重要"。
2. 🔴 条目的处理决策统一填"→第4节"，内容展开在第4节完成，此处不重复。
3. 🔵 的回看理由必须说明：如果只看文字摘要，会损失什么？（情绪临场感 / 语气停顿 / 案例身临其境 / 复杂推理须跟着走一遍）。
4. ⚪ 只需一行，不写原因，不进入后续任何步骤。
5. 无时间戳时用位置标记（约前20% / 中段 / 结尾），不要编造时间戳。

【核心知识 N】

- **来源锚点**：（引用第3节对应行的时间戳/位置，直接复制，不重复描述）
- **触发情境**：这个观点是在回应什么问题、化解什么矛盾时提出的？

- **推理链**：用"因为A → 所以B → 因此C"格式拆解作者的论证路径。必填，不接受只写结论。
- **可迁移方法**：能提炼成可操作步骤的，写出来；不能的，直接写"仅概念层，无直接操作"。
- **适用边界**：这个观点在什么条件下成立？在什么条件下会失效？
- **可信度标注**：从以下三项中选一：论证充分 / 论证不足（说明跳跃了哪一步）/ 待验证（说明需要什么条件才能确认）
