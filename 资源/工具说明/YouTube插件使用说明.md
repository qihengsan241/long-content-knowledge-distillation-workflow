# 简约翻译插件 / YouTube 字幕使用说明

## 当前定位

用户已安装的简约翻译插件是 YouTube 直读字幕轨失败后的第二层来源。第一层先用 `youtube-transcript-api` 读取已有人工字幕或自动字幕；失败后才使用插件。

插件不是账号自动化入口。不要读取或保存浏览器登录信息、Cookie、API Key、Token、插件私有存储或其他个人账户数据。

## 自动协作路线

1. 先运行 `脚本/提取YouTube字幕.py`。
2. 直读失败后运行 `opencli doctor`，确认浏览器桥正常。
3. 打开或绑定真实 YouTube 视频页，读取页面结构。
4. 找到简约翻译注入的“下载字幕 (VTT)”按钮并点击。
5. 在系统“另存为”对话框中，将字幕保存到本次任务输出目录。
6. 使用以下命令导入：

```bash
python 脚本/导入文本文件.py "插件字幕.vtt" --来源链接 "YouTube链接" --平台 YouTube --提取方式 "简约翻译插件" --简约插件清洗
```

`--简约插件清洗` 只移除插件产生的 `[Translation failed]` / `[翻译失败]` 占位符，不改写字幕正文。

## 路线 A：下载字幕文件

1. 在 YouTube 视频页确认存在字幕或自动字幕。
2. 使用简约翻译插件下载完整字幕，优先保留原语言和时间戳。
3. 将 `.txt`、`.md`、`.srt` 或 `.vtt` 文件导入：

```bash
python 脚本/导入文本文件.py "字幕文件路径"
```

4. 建议添加 `--简约插件清洗 --提取方式 "简约翻译插件"`。
5. 检查 `输出/逐字稿.md`，确认内容是字幕正文，而不是标题、简介、章节名、评论或推荐内容。

## 路线 B：复制字幕文本

1. 使用简约翻译插件复制完整字幕。
2. 在前端“手动粘贴文本”区域录入，或运行：

```bash
python 脚本/半自动录入.py
```

3. 粘贴完成后单独输入一行 `END`。

如果字幕带时间戳，工作流会尽量保留；没有时间戳时会标记为“无精确时间戳”，不会编造时间。

## 浏览器协作边界

- 如果插件把复制或下载按钮直接注入 YouTube 页面，Codex 可以先读取页面真实结构，再操作页面中可见的控件。
- 如果控件只存在于浏览器工具栏的扩展弹窗，用户负责点击复制或下载，Codex 从字幕文件或已复制文本继续处理。
- 不读取扩展内部存储、浏览器凭据、Cookie 或登录数据库，不绕过视频权限、地区、付费或私密限制。

## 质量检查

- 字幕必须非空，并与视频口播内容相符。
- 优先选择完整字幕；明显缺段、语言错误或只有标题简介时停止知识脱水。
- 自动字幕、机器翻译字幕应在来源说明中标记，关键引文需要回看视频核对。
- 不把标题、简介、章节、评论、弹幕或推荐内容当作逐字稿。

## 完整顺序

1. `脚本/提取YouTube字幕.py` 直接读取 YouTube 字幕轨。
2. 简约翻译插件下载 VTT 并导入。
3. `脚本/下载字幕或音频.py` 使用 `yt-dlp`。
4. 获取本地音频后运行 `脚本/转写音频.py`。
5. 仍失败时，由用户手动提供字幕或转录稿。
