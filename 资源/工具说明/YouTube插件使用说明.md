# 简约翻译插件 / YouTube 字幕使用说明

## 当前定位

用户已安装的简约翻译插件是本工作流首选的 YouTube 半自动字幕来源。它负责取得真实字幕；本项目只负责导入、标准化、知识脱水和 Markdown 输出。

插件不是账号自动化入口。不要读取或保存浏览器登录信息、Cookie、API Key、Token、插件私有存储或其他个人账户数据。

## 路线 A：下载字幕文件

1. 在 YouTube 视频页确认存在字幕或自动字幕。
2. 使用简约翻译插件下载完整字幕，优先保留原语言和时间戳。
3. 将 `.txt`、`.md`、`.srt` 或 `.vtt` 文件导入：

```bash
python 脚本/导入文本文件.py "字幕文件路径"
```

4. 检查 `输出/逐字稿.md`，确认内容是字幕正文，而不是标题、简介、章节名、评论或推荐内容。

## 路线 B：复制字幕文本

1. 使用简约翻译插件复制完整字幕。
2. 在前端“手动粘贴文本”区域录入，或运行：

```bash
python 脚本/半自动录入.py
```

3. 粘贴完成后单独输入一行 `END`。

如果字幕带时间戳，工作流会尽量保留；没有时间戳时会标记为“无精确时间戳”，不会编造时间。

## 浏览器协作边界

- 如果插件把复制或下载按钮直接注入 YouTube 页面，Codex 可以先读取页面真实结构，再操作页面中可见的控件。
- 如果控件只存在于浏览器工具栏的扩展弹窗，用户负责点击复制或下载，Codex 从字幕文件或已复制文本继续处理。
- 不读取扩展内部存储、浏览器凭据、Cookie 或登录数据库，不绕过视频权限、地区、付费或私密限制。

## 质量检查

- 字幕必须非空，并与视频口播内容相符。
- 优先选择完整字幕；明显缺段、语言错误或只有标题简介时停止知识脱水。
- 自动字幕、机器翻译字幕应在来源说明中标记，关键引文需要回看视频核对。
- 不把标题、简介、章节、评论、弹幕或推荐内容当作逐字稿。

## 失败后的顺序

1. 尝试 `baoyu-youtube-transcript` Skill。
2. 尝试 `脚本/提取YouTube字幕.py`。
3. 尝试 `脚本/下载字幕或音频.py`。
4. 获取本地音频后尝试 `脚本/转写音频.py`。
5. 仍失败时，由用户手动提供字幕或转录稿。
