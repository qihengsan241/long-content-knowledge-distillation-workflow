# 视频硬字幕 OCR 说明

## 适用场景

当字幕已经烧录在视频画面中、无法作为独立字幕轨下载时，可使用本地 OCR 工具识别。没有画面字幕的视频不适合 OCR，应使用音频转写。

## 推荐工具

- 项目：Video Subtitle Extractor（VSE）
- 官方仓库：https://github.com/YaoFANGUK/video-subtitle-extractor
- 许可证：Apache-2.0
- 当前评估版本：v2.2.0
- 输出：SRT、TXT
- 平台：Windows、macOS、Linux

VSE 模型和依赖较重，因此只作为外部可选工具，不打包进本 Skill，也不由前端自动安装。

## 使用路线

1. 用户自行准备有权处理的本地视频文件。
2. 使用 VSE 识别画面中的硬字幕并导出 `.srt`。
3. 将 SRT 导入本项目：

```bash
python 脚本/导入文本文件.py "本地字幕.srt"
```

4. 继续生成最终提示词、知识脱水结果和黑曜石 Markdown。

## 注意事项

- VSE 项目路径建议避免中文、空格和特殊字符。
- OCR 结果可能有错字、漏字和时间轴偏移，进入知识脱水前应人工抽查。
- 不要把视频标题、简介、评论或弹幕当作逐字稿。
- 工具只处理本地文件，不用于绕过登录、付费、私密内容或平台权限。
