# Kedou / 蝌蚪视频解析网站使用说明

工具地址：https://www.kedou.life/

## 当前定位

Kedou 在本工作流中只作为半自动第三方工具使用。脚本不会自动爬取 Kedou，也不会假设 Kedou 能全平台稳定提取逐字稿。

## 建议用法

1. 打开 Kedou 网站。
2. 手动粘贴原始视频链接或文章链接。
3. 根据页面提供的能力尝试字幕下载、文本提取或视频解析。
4. 如果拿到了字幕、逐字稿或正文，复制文本。
5. 回到命令行 `脚本/半自动录入.py`，把文本粘贴进去。
6. 单独输入一行 `END` 结束录入。

## 平台建议

- B站：优先尝试字幕下载。
- 抖音：优先尝试视频解析；如果没有字幕，后续可能需要音频转写。
- 小红书：图文可尝试文本提取；视频可能无法直接获得逐字稿。
- 知乎 / CSDN / 博客园 / 简书：可尝试文本提取，也可以手动复制正文。
- 普通网页：可尝试文本提取，也可以手动复制正文。
- YouTube：可尝试字幕下载，但优先建议使用 YouTube 字幕读取插件。

## 禁止事项

- 不要只根据标题、封面、简介或评论生成逐字稿。
- Kedou 没有提取到文本时，不要进入知识脱水。
- 不要把 Kedou 输出当作必然准确；需要人工快速检查是否漏段、乱序或夹杂广告。
