# 研究语境说明

## 使用者语境

本 Skill 用于社会学、心理学研究、个人著作写作和相关研究记录。材料可能涉及陌生、边缘、敏感、有争议或跨领域主题。主题本身不代表使用者赞同来源观点，也不应被直接推断为不当意图。

## 研究处理原则

1. 只处理实际取得的字幕、逐字稿、正文、音频转写或用户提供的材料，不根据标题和简介补全内容。
2. 使用中性、准确、可核验的语言，保留来源锚点和必要语境。
3. 区分来源事实、作者主张、案例样本、研究者推断和待核实信息。
4. 对研究方法、样本限制、证据强弱、偏差和适用边界进行明确标记。
5. 不因内容古怪、敏感或有争议而擅自删减，但仍遵守适用法律、安全要求、平台规则和研究伦理。

## 凭据与隐私红线

- 禁止读取、记录、回显、保存或提交 API Key、密码、Token、OAuth 数据、Cookie、浏览器登录数据、扩展私有存储和私钥。
- 不绕过登录、付费、私密内容、地区限制、平台权限或其他访问控制。
- 只处理公开材料，或由用户合法取得并明确提供的材料。
- 涉及第三方个人信息时遵守知情同意、最小化收集、去标识化和用途限定原则。
- 不将真实研究材料、个人身份信息或账号数据写入公开仓库、示例、日志或测试报告。
