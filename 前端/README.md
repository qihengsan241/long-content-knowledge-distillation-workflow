# 长内容知识脱水工作台

这是 v0.4 新增的本地 Streamlit 前端。它只作为操作面板，调用现有 Python 脚本，不重写后端核心逻辑。

## 如何启动前端

在项目根目录运行：

```bash
streamlit run 前端/知识脱水工作台.py
```

启动后打开本地页面，通常是：

```text
http://localhost:8501
```

## 页面区域作用

### 顶部状态区

显示当前工作流版本、模型供应商、模型名称、输出目录状态和当前流程状态。

### 文本来源中心

提供多种文本入口：

- 网页文章链接：调用网页正文提取脚本。
- 本地文本/字幕文件上传：支持 `.txt`、`.md`、`.srt`、`.vtt`。
- 手动粘贴文本：粘贴长文、字幕或转录稿。
- YouTube 链接（实验）：尝试提取 YouTube 字幕。
- 通用视频链接（实验）：尝试 yt-dlp 提取字幕或音频。
- 本地音频/视频转写：上传本地音频或视频，尝试 faster-whisper 转写。

### 平台识别与推荐路线区

根据输入链接识别平台，并显示推荐处理路线。

### 流程操作区

提供核心按钮：

- 生成最终提示词。
- 调用 DeepSeek 知识脱水。
- 整理为黑曜石 Markdown。
- 一键运行完整流程。

### 流程进度区

显示五个步骤状态：

1. 获取文本
2. 标准化逐字稿
3. 生成最终提示词
4. 模型知识脱水
5. 黑曜石 Markdown 输出

### 输出预览区

预览以下文件：

- `输出/逐字稿.md`
- `输出/最终提示词.md`
- `输出/知识脱水结果.md`
- `输出/黑曜石笔记.md`
- `输出/模型调用日志.md`

### 文件操作区

提供打开输出文件夹、下载黑曜石 Markdown、复制最终提示词、复制黑曜石 Markdown、查看模型调用日志和清空本次输出。

### 错误提示区

显示人话错误提示和下一步建议。

## 抖音实验处理区

抖音实验处理区用于处理 `yt-dlp` 普通尝试失败后的授权模式和本地文件兜底。

包含：

- 抖音链接输入框。
- 抖音普通尝试。
- 使用浏览器 Cookie 尝试。
- 上传 `cookie.txt` 尝试。
- 上传本地视频/音频文件。
- 硬字幕 OCR 外部工具入口。
- 音频转写入口。
- Cookie 安全提示。

浏览器 Cookie 和 `cookie.txt` 模式默认不会启用。必须先勾选安全确认。

Cookie 不会写入日志，`cookie.txt`、`*.cookies.txt` 和 `cookies/` 已加入 `.gitignore`。

## 常见问题

### DeepSeek 调用失败怎么办

检查项目根目录 `.env`：

```text
LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的 DeepSeek API Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
```

不要把 API Key 粘贴到聊天或日志里。确认配置后重新点击“调用 DeepSeek 知识脱水”。

### 网页文章提取失败怎么办

优先手动复制网页正文，粘贴到“手动粘贴文本”区域，再点击“保存为逐字稿”。

### 输出文件没有生成怎么办

按顺序检查：

1. 是否已经生成 `输出/逐字稿.md`。
2. 是否已经点击“生成最终提示词”。
3. DeepSeek 调用是否成功。
4. 是否已经点击“整理为黑曜石 Markdown”。
5. 查看 `输出/模型调用日志.md`。

### 实验功能失败怎么办

YouTube 自动字幕和 yt-dlp 入口仍受视频字幕轨与平台限制。如果失败，优先导入简约翻译插件导出的字幕；没有字幕时提供本地媒体，用 faster-whisper 转写。

### 本地音频/视频转写失败怎么办

先确认依赖：

```bash
python -m pip install -r 依赖清单.txt
ffmpeg -version
```

如果 `ffmpeg -version` 无法运行，请先安装 ffmpeg 并加入系统 PATH。上传视频文件（如 `.webm`、`.mp4`）时尤其需要 ffmpeg。

转写器默认自动检测设备：有可用 NVIDIA CUDA 时优先使用 GPU，否则使用 CPU。当前机器已经检测到 RTX 3060；真实效果仍应以实际本地媒体转写结果为准。

支持文件：

```text
mp3 / m4a / wav / webm / mp4
```

如果转写结果为空，说明文件中可能没有清晰人声，建议先手动转写，再用“手动粘贴文本”或“本地文本/字幕文件上传”导入。

如果视频画面中有烧录字幕，可在外部使用 Video Subtitle Extractor 导出 SRT，再从“本地文本/字幕文件上传”导入。外部工具不会由前端自动安装或运行。

### 抖音 Cookie 模式失败怎么办

先确认你能在对应浏览器中正常打开这个公开视频。然后检查：

- 是否已经勾选 Cookie 安全确认。
- 是否选择了正确浏览器。
- 如果使用 `cookie.txt`，文件是否过期。
- 是否仍被平台限制。

如果仍失败，不要反复重试。改用本地文件兜底：手动保存视频或音频，再走 OCR 字幕提取或音频转写。

```text
→ 生成逐字稿
→ 生成最终提示词
→ 调用 DeepSeek 知识脱水
→ 整理为黑曜石 Markdown
```
